# 투두 리스트 앱 (Todo List App)

로컬에서 구동 가능한 간단한 투두 리스트 애플리케이션입니다.

## 기능 (Features)

- ✅ 할 일 추가
- ✅ 할 일 완료/미완료 토글
- ✅ 할 일 삭제
- ✅ 필터링 (전체/진행 중/완료됨)
- ✅ 통계 표시 (전체/진행 중/완료 개수)
- ✅ 로컬 JSON 파일에 자동 저장
- ✅ 모두 완료로 표시
- ✅ 완료된 항목 일괄 삭제

## 설치 방법 (Installation)

1. 필요한 패키지 설치:
```bash
pip install -r requirements.txt
```

또는:
```bash
pip install streamlit
```

## 실행 방법 (How to Run)

```bash
streamlit run todo_app.py
```

앱이 자동으로 브라우저에서 열립니다 (기본 주소: http://localhost:8501)

## 사용 방법 (Usage)

1. **할 일 추가**: 상단 입력창에 할 일을 입력하고 "추가" 버튼을 클릭합니다.
2. **완료 표시**: 각 항목 왼쪽의 체크박스를 클릭하여 완료/미완료 상태를 변경합니다.
3. **삭제**: 각 항목 오른쪽의 🗑️ 버튼을 클릭하여 삭제합니다.
4. **필터링**: "전체", "진행 중", "완료됨" 중 선택하여 항목을 필터링합니다.
5. **일괄 작업**: 하단의 "모두 완료로 표시" 또는 "완료된 항목 삭제" 버튼을 사용합니다.

## 데이터 저장 (Data Storage)

모든 할 일은 `todos.json` 파일에 자동으로 저장됩니다. 앱을 종료하고 다시 시작해도 데이터가 유지됩니다.

## 기술 스택 (Tech Stack)

- Python 3
- Streamlit
- JSON (로컬 저장소)
